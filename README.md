# Orbit Wars Web Game

Kaggle 대회 **[Orbit Wars](https://www.kaggle.com/competitions/orbit-wars)**에서 아이디어를 얻어 제작한 실시간 우주 행성 점령 전략 웹게임입니다.  
플레이어는 함대를 보내 행성을 점령하고, 병력을 생산하며, AI 라이벌과 경쟁합니다.

본 프로젝트는 단순한 웹게임 구현을 넘어 규칙 기반 AI 전략, AI 대 AI 자동 대전, 난이도 설정, 무작위 이벤트, 전략 비교 데이터 저장 기능까지 포함한 교육용 미니 전략 게임입니다.

---

## 1. 프로젝트 개요

**[Orbit Wars Web Game](https://orbit-wars-web-game-theta.vercel.app/)**은 행성을 점령하고 함대를 이동시키는 실시간 우주 전략 게임입니다.

게임의 핵심 흐름은 다음과 같습니다.

1. 행성이 시간이 지남에 따라 병력을 생산합니다.
2. 플레이어 또는 AI가 보유 행성을 선택합니다.
3. 병력 일부를 함대로 출격시킵니다.
4. 함대가 목표 행성으로 이동합니다.
5. 도착 후 전투가 발생합니다.
6. 병력이 더 많은 쪽이 행성을 점령합니다.
7. 제한 시간 종료 또는 특정 조건 달성 시 승패가 결정됩니다.

## 4. 실행 방법

### 웹게임 실행

프로젝트 루트에서 다음 명령어를 실행합니다.

```bash
python src/main.py
```

## 7. 게임 데이터 구조

### 행성 데이터

행성은 다음과 같은 정보를 가집니다.

```js
{
  x: 0.18,
  y: 0.25,
  r: 27,
  owner: "player",
  units: 24,
  prod: 2,
  name: "NOVA"
}
```

각 항목의 의미는 다음과 같습니다.

| 항목 | 설명 |
|---|---|
| `x`, `y` | 캔버스 내 행성 위치 |
| `r` | 행성 반지름 |
| `owner` | 행성 소유자 |
| `units` | 현재 병력 |
| `prod` | 병력 생산량 |
| `name` | 행성 이름 |

---

### 함대 데이터

함대는 다음과 같은 정보를 가집니다.

```js
{
  from: sourcePlanet,
  to: targetPlanet,
  owner: "player",
  amount: 12,
  progress: 0,
  duration: 3.2
}
```

각 항목의 의미는 다음과 같습니다.

| 항목 | 설명 |
|---|---|
| `from` | 출발 행성 |
| `to` | 목표 행성 |
| `owner` | 함대 소유자 |
| `amount` | 출격 병력 수 |
| `progress` | 이동 진행률 |
| `duration` | 목표 행성까지 이동하는 데 걸리는 시간 |

## 8. 전투 규칙

함대가 목표 행성에 도착하면 공격 병력과 방어 병력을 비교합니다.

```text
공격 병력 > 방어 병력
→ 행성 점령

공격 병력 <= 방어 병력
→ 공격 실패
→ 방어 병력 감소
```

행성 점령 시 플레이어는 점수를 획득합니다.

- 행성 간 거리


## 10. AI 전략

### 공격형

- 플레이어 행성을 우선 목표로 선택
- 가까운 적 행성을 선호
- 공격 가능한 경우 병력의 일부를 빠르게 출격
- 공격 빈도가 높음

### 방어형

- 공격보다 병력 축적을 우선
- 생산량이 높은 행성을 평가
- 공격 조건이 충족되지 않으면 대기
- 안정적인 확장을 목표로 함

### 확장형

- 중립 행성을 우선 공격
- 생산량이 높은 중립 행성을 선호
- 초반 영토 확장에 집중

### 균형형

다음 요소를 종합적으로 고려하여 목표를 선택합니다.

- 거리
- 목표 병력
- 생산량
- 중립 행성 여부
- 적 행성 여부

## 12. AI 대 AI 자동 대전

AI 대 AI 모드에서는 플레이어의 입력 없이 두 AI가 자동으로 대결합니다.

작동 방식은 다음과 같습니다.

1. 양쪽 행성이 병력을 생산합니다.
2. 일정 시간마다 각 AI가 병력이 가장 많은 행성을 찾습니다.
3. 전략에 따라 목표 행성을 평가합니다.
4. 공격 조건이 충족되면 함대를 출격시킵니다.
5. 전투 결과에 따라 행성 소유자가 변경됩니다.
6. 게임 종료 후 결과 통계를 표시합니다.

자동 대전 결과에는 다음 정보가 포함됩니다.

- 승패
- 최종 점수
- 점령 행성 수
- 함대 발사 횟수
- 행성 점령 횟수
- 이벤트 발생 횟수
- 게임 진행 시간

## 13. 운석·혜성 이벤트

게임 중 무작위 이벤트가 발생합니다.

### 이벤트 사전 경고

이벤트 발생 약 3초 전에 화면 상단에 경고가 표시됩니다.

예시:

```text
⚠ 운석 접근 중: 3초 후 NOVA에 도착합니다.
```

---

### 운석 이벤트

- 무작위 행성에 충돌
- 해당 행성의 병력 일부 감소
- 이벤트 로그 기록
- 운석 발생 횟수 통계에 저장

---

### 혜성 이벤트

- 특정 행성 주변을 통과
- 인접 행성의 생산량 증가
- 이벤트 로그 기록
- 혜성 발생 횟수 통계에 저장

이벤트는 무작위로 발생하지만, 난이도에 따라 피해량이 달라집니다.

## 14. 누적 통계 저장

게임 통계는 브라우저의 `localStorage`에 저장됩니다.

따라서 다음 상황에서도 통계가 유지됩니다.

- 게임 재시작
- 페이지 새로고침
- 브라우저 종료 후 재접속

저장 항목 예시는 다음과 같습니다.

```js
{
  launches: 0,
  captures: 0,
  events: 0,
  wins: 0,
  games: 0,
  meteorites: 0,
  comets: 0
}
```

통계 항목의 의미는 다음과 같습니다.

| 항목 | 설명 |
|---|---|
| `launches` | 실제 함대가 출발한 횟수 |
| `captures` | 행성을 새로 점령한 횟수 |
| `events` | 운석과 혜성을 합친 이벤트 횟수 |
| `meteorites` | 운석 발생 횟수 |
| `comets` | 혜성 발생 횟수 |
| `wins` | 승리 횟수 |
| `games` | 종료된 게임 수 |

통계는 `누적 통계 초기화` 버튼으로 삭제할 수 있습니다.

## 15. AI 전략 비교 실험

전략 비교는 웹 화면의 단순 예상값이 아니라 별도의 시뮬레이션 엔진을 사용합니다.

비교 전략 조합은 다음과 같습니다.

- 공격형 vs 방어형
- 공격형 vs 확장형
- 공격형 vs 균형형
- 방어형 vs 확장형
- 방어형 vs 균형형
- 확장형 vs 균형형

각 조합은 30회씩 실행됩니다.

```text
6개 조합 × 30회 = 총 180경기
```

공정한 실험을 위해 다음 조건을 동일하게 설정했습니다.

- 동일한 행성 배치
- 동일한 시작 병력
- 동일한 생산량
- 동일한 중급 난이도
- 동일한 운석·혜성 규칙
- 선공 전략 교대
- 동일한 랜덤 시드 규칙

---

## 18. 실험 결과 해석 시 주의점

현재 실험은 다음 조건을 기준으로 합니다.

- 중급 난이도만 사용
- 고정된 행성 배치 사용
- 30회 반복
- 운석·혜성 이벤트 포함
- 랜덤 요소 포함

따라서 결과는 절대적인 전략 순위라기보다 **현재 규칙과 맵에서의 비교 결과**로 해석해야 합니다.

보고서에는 다음과 같이 작성할 수 있습니다.

> 각 AI 전략 조합을 30회씩 총 180회 자동 대전하였다. 모든 경기는 동일한 행성 배치, 시작 병력, 생산량, 난이도와 이벤트 규칙을 사용했으며 선공 전략을 교대하였다. 결과는 JSON 및 CSV 파일로 저장하고, 승률·평균 점수·평균 점령 행성 수·평균 게임 시간·평균 발사 횟수를 비교하였다.

- UI 문구 한국어화
- 전략 비교 기능 설계

## 20. 개발 결과

초기 기획의 필수 목표였던 플레이 가능한 실시간 Orbit Wars 미니 게임을 구현했습니다.

- 규칙 기반 AI
- AI 전략 선택

- 난이도 선택
- 운석·혜성 이벤트
- 누적 통계 저장
- 결과 통계 기록
- 전략 비교 데이터 저장

현재 프로젝트는 기본적인 게임 플레이와 AI 대전이 가능한 상태입니다.  
또한 자동 대전 데이터를 기반으로 전략별 평균 점수와 승률을 분석할 수 있는 구조를 갖추고 있습니다.
